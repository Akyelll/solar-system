# 🌌 Solar System Web Experience

Uma aplicação web interativa que simula o Sistema Solar com visualização dinâmica, páginas dedicadas para cada planeta e navegação estruturada entre conteúdos astronômicos.

Projeto desenvolvido com foco em experiência visual, organização de conteúdo e prática de desenvolvimento frontend com HTML, CSS e JavaScript puro.

---

## 🎯 Visão do Projeto

Este projeto foi criado como uma experiência educacional e de portfólio com o objetivo de simular um ambiente espacial interativo e informativo.

A proposta não é apenas exibir planetas, mas estruturar um sistema de navegação consistente e escalável entre múltiplas páginas, simulando um produto real de conteúdo educacional.

---

## 🧠 Problema Resolvido

A aplicação resolve o desafio de apresentar conteúdo astronômico de forma:

- Visualmente intuitiva
- Navegável entre múltiplas páginas
- Organizada por categorias (planetas e sistema solar)
- Leve e sem dependência de frameworks

---

## ⚙️ Stack Utilizada

- HTML5 (estrutura semântica)
- CSS3 (layout, responsividade e animações)
- JavaScript (interações básicas e DOM manipulation)

---

## ⚙️ Funcionalidades

- Navegação entre páginas do sistema solar
- Cards interativos com informações dos planetas
- Página individual para cada planeta
- Botão de retorno ao topo
- Menu lateral com navegação rápida
- Animação visual do sistema solar no index

---

## 📚 Aprendizados

Durante o desenvolvimento foi possível praticar:

- Estruturação de sites multi-página
- Organização de assets e arquivos
- Posicionamento e layout com CSS
- Manipulação básica de eventos com JavaScript
- Pensamento de projeto completo (não apenas páginas isoladas)
